`tuios.dev/plot` draws charts as terminal cells. It has eleven chart kinds: bar (horizontal and vertical), line, area, sparkline, gauge, histogram, heatmap, pie (a donut or a full disc), mirrored bars, inline bars for table cells, and a world map. It holds no colour and writes no escape sequence. Each cell has a role, and your program picks the colour.

## The tplot command [#tplot-command]

`tplot` draws a chart from CSV, TSV, JSON or plain numbers, from a file or standard input. It needs Go 1.25 or newer:

```bash
go install tuios.dev/plot/cmd/tplot@latest
```

Each tuios release from v0.11.0 also carries a `tplot` archive for Linux, macOS, Windows and FreeBSD, on x86_64 and arm64. Download it from the [releases page](https://github.com/Gaurav-Gosain/tuios/releases), or install it with a package manager:

```bash
brew install --cask gaurav-gosain/tap/tuios-plot   # macOS and Linux
yay -S tuios-plot-bin                              # Arch Linux, from the AUR
```

```bash
printf 'session,6.2\napp,4.8\nvt,3.1\n' | tplot
seq 1 50 | awk '{print sin($1/5)}' | tplot --kind line
tplot --kind pie shares.csv
echo '{"US": 410, "DE": 120, "SG": 14}' | tplot --kind map --log
```

- A text column gives the labels. Each column of numbers is a series. A first row of names is a header.
- JSON can be `[1, 2, 3]`, `{"a": 1}`, `{"rx": [1, 2], "tx": [3, 4]}`, rows as arrays, or rows as objects.
- Without `--kind`, a few labelled values draw as bars, and other data as a line chart. The kinds are `bar`, `column`, `line`, `area`, `spark`, `hist`, `heatmap`, `pie`, `donut`, `gauge` and `map`.
- The colours are the 16 ANSI colours, so the chart takes the colours of the terminal's theme. Without colour, a chart that needs colour to tell its parts apart uses ASCII marks.
- `tplot -h` lists every flag.

The command is `tplot`, because GNU plotutils already has a `plot` command. The Homebrew cask and the AUR package keep the library's name.

## How it works

- A chart draws into a grid of the size you give it. The grid is always that size, and each row is exactly that wide.
- Each cell holds one grapheme, its width, a role such as `series1` or `mute`, and a background role for half blocks.
- `g.At(x, y)` gives one cell. `g.String()` gives the text with no colours.
- Your program maps each role to a colour at the colour depth of the terminal. [loom](/docs/libraries/loom) does this with its `Palette`.

### Mirrored bars

<LibShot name="plot/mirror" alt="Download as green dot columns above a baseline and upload as pink dot columns below it, a peak marker with its value over each half, and peak, average and total in the corners" />

`Mirror` draws two series around one baseline, such as download and upload, tokens in and out, or reads and writes. Each value is one column of braille dots, and the newest value is at the right edge. Each half scales to its own peak, and `Shared` gives both one scale. ### Inline bars

`InlineBar` is a bar one row high for a table cell. It draws no label, so the cell next to it can hold the value. By default it is a lower half block, exact to half a cell, so the bars of a table stay apart. `Style: plot.BarBlocks` fills the row with eighth blocks. Give every row the same `Max`, so the bars compare.

### World map

<include cwd lang="go">tools/libshots/snippets/plot-map.txt</include>

<LibShot name="plot/map" alt="A world map in braille dots, with thirteen countries shaded by traffic on a log scale, two host markers, and a legend of five shades right under the map" />

`Map` draws the land in the `track` role, and fills each country with a value with a shade of `Ramp`, `heat1` to `heat5` by default. Countries are ISO 3166-1 alpha-2 codes. The projection is equirectangular, from 180° W to 180° E and from 84° N to 60° S. The map keeps its true shape and is centred, and fills a box at most a tenth past that shape. `Fit` returns the cells it takes, so the legend can go right under it. Codes are case-blind, and when two keys name one country the larger value counts. A country that is the larger part of no cell, such as Singapore, takes the cell it covers most, or the nearest free cell, and shows only when it has a value. `Legend` writes `>=` in ASCII. A program that draws no map does not link the map data.

Credit: the idea and the look come from [iptop](https://github.com/franlol/iptop) by franlol (MIT).

Map data: [Natural Earth](https://www.naturalearthdata.com/) 1:50m Admin 0 Countries, version 5.1.1, which is in the public domain.

## Modes

A mode sets the glyphs a chart can use. Use the best mode that the terminal and its font can show.

| Mode | Lines and areas | Bars, sparklines, gauges |
| --- | --- | --- |
| `Braille` | Braille dots, 2 by 4 per cell | Eighth blocks |
| `Blocks` | Eighth blocks | Eighth blocks |
| `ASCII` | `*` and `:` | `#`, `-` and `[ ]` |

## Theme roles

A role names a colour. The names are the TML roles, plus `track` for the empty part of a gauge or a bar, and `heat1` to `heat5`. `plot.Fade(role, k)` names a role faded `k` steps toward the ground, such as `series1/2`, and `Role.Faded` splits it. Draw fade `k` as the base colour mixed about `k` fifths toward the ground. `plot.SeriesRole(i)` gives the role of series i, and cycles after six.

## How do I

- **Fix the range of a chart?** Set `Min` and `Max`. Both 0 means automatic.
- **Format the values?** Set `Format`, such as `plot.Compact` or your own function.
- **Draw a legend?** Call `DrawLegend(grid, x, y, chart.Legend(), mode)`, and give it a row of its own.
- **Colour one bar?** Set `Roles`, one role per bar.
- **Draw a chart in a TML document?** Use the chart components through [loom](/docs/libraries/loom), such as `<bar data="state.rows" x="pkg" y="secs"/>`.
- **Print a chart with no colour?** Call `grid.String()`.

## Rules

- Every chart is total. NaN and infinite values count as missing. Empty data draws an empty grid.
- Sizes that a caller could pass unchecked are bounded: a grid is at most 4096 cells a side, and a line draws at most 64 series.
- Labels are cut with an ellipsis to fit. Control characters are dropped, and invalid UTF-8 shows as `?`.

## Where it fits

- [loom](/docs/libraries/loom) uses plot to draw the TML chart components, and maps the roles with its palette.
- tuios draws the charts of `tuios tml show` surfaces with it.
- Widths come from `charmbracelet/x/ansi`, the same width functions that tuios uses. The package imports nothing else outside the standard library.

## Versions

The module is at v0. The API can change between minor versions. Its tags have the folder name as a prefix, such as `plot/v0.1.0`. The source is in the [plot folder](https://github.com/Gaurav-Gosain/tuios/tree/main/plot) of the tuios repository, under the MIT licence.
