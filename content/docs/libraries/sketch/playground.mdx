<SketchPlayground />

The diagram changes shape as you type: each new drawing moves from the last one. sketch is the same Go code as [`tuios.dev/sketch`](/docs/libraries/sketch), compiled to WebAssembly. It runs in a worker in this tab and sends nothing to a server.

- Pick an example. The showcases are larger drawings with colours, groups and notes. The other examples show 32 of the 33 diagram types. Only info, which shows the version of pele, has no example.
- Pick a theme. **Match the site** follows the light or dark mode of these docs.
- **Copy link** puts the diagram and the theme in the address. The link opens the same drawing.
- **Copy SVG** and **PNG** give the drawing with the theme colours written in.

An error marks its line in the editor and keeps the last good drawing on screen. A Mermaid type that pele does not draw gives the error `unsupported-diagram`.
