Some parts of tuios are Go modules of their own. You can import one without the rest of tuios. Each module has a `tuios.dev` import path. The code is in the [tuios repository](https://github.com/Gaurav-Gosain/tuios), in a folder with the same name.

<Cards>
  <Card title="progstatus" href="/docs/libraries/progstatus">
    Read and write the Program Status Protocol, OSC 7501. A program says what it does, and a terminal shows it.
  </Card>
  <Card title="vt" href="/docs/libraries/vt">
    A terminal emulator in pure Go. Feed it what a program prints, and read the screen, the scrollback and the modes.
  </Card>
  <Card title="swatch" href="/docs/libraries/swatch">
    Read the desktop's colour theme as a palette with semantic roles, and follow it while your program runs. The first source is Omarchy.
  </Card>
  <Card title="shot" href="/docs/libraries/shot">
    Render a terminal screen to PNG, SVG, HTML, ANSI or text, with an optional window frame.
  </Card>
  <Card title="tml" href="/docs/libraries/tml">
    The TML language: parse, print and validate documents for terminal surfaces, with bindings, actions and JSON Patch.
  </Card>
  <Card title="loom" href="/docs/libraries/loom">
    Draw TML documents into terminal cells: flex layout, theme roles at every colour depth, redraws of only what changed, and local keys and clicks.
  </Card>
  <Card title="plot" href="/docs/libraries/plot">
    Bar, line, area, sparkline, gauge and histogram charts as terminal cells, in braille, block elements or ASCII.
  </Card>
  <Card title="Embed tuios" href="/docs/library">
    Run the whole window manager inside your own Bubble Tea program, with the pkg/tuios package.
  </Card>
</Cards>

## Install a library

```bash
go get tuios.dev/progstatus
go get tuios.dev/vt
go get tuios.dev/swatch
go get tuios.dev/shot
go get tuios.dev/tml
go get tuios.dev/loom
go get tuios.dev/plot
```

The go command asks tuios.dev where the code is. Go 1.25 or later can fetch a library directly. With the default module proxy, any Go version can fetch it.

## Versions

Each library has its own versions. A library tag has the folder name as a prefix, such as `progstatus/v0.1.0`. The libraries are at v0, so the API can change between minor versions.

Report a problem in the [tuios issue tracker](https://github.com/Gaurav-Gosain/tuios/issues).
