## `agent-activity` <Since verb="agent-activity" /> [#agent-activity]

Read what the agent in a pane has been doing, from the ring of hook events the daemon keeps for it: prompts, tool calls and their results, finished turns, subagents starting and stopping, conversations starting, and the commands its shell ran, the newest 256 of them. A pane gets a ring on the first hook report that carries activity, and loses it when it closes; the ring is daemon memory only. With recap, a summary of it since a time. The text is the agent's, cleaned and masked, and marked untrusted.

| Param       | Type   | Required | Default | Description                                                                                                              |
| ----------- | ------ | -------- | ------- | ------------------------------------------------------------------------------------------------------------------------ |
| `session`   | string |          |         | Session name. Omit from a pane for the pane's own session, and from outside every pane for the most recently active one. |
| `window`    | string |          |         | Window id or name. Omit to target the focused window.                                                                    |
| `since`     | int    |          |         | Only entries after this time, in unix nanoseconds.                                                                       |
| `since_seq` | int    |          |         | Only entries after this seq.                                                                                             |
| `limit`     | int    |          | `64`    | At most this many entries, newest last, up to 256.                                                                       |
| `recap`     | bool   |          | `false` | Also summarise the entries: turns, files, commands, the last test run and what the agent last said.                      |

| Result field | Type      | Description                                                                                                                                                                                                                                                               |
| ------------ | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `entries`    | \[]object | Oldest first: seq, at (unix nanoseconds), kind (prompt, tool, tool\_done, tool\_failed, turn\_end, subagent\_start, subagent\_stop, session\_start, command or state), tool, target, files, ok, exit and text per entry. Empty for a pane with no ring.                   |
| `window`     | string    | The window id the entries are of.                                                                                                                                                                                                                                         |
| `last_seq`   | int       | The seq of the newest entry the ring holds.                                                                                                                                                                                                                               |
| `recap`      | object    | With recap, over every entry after since and since\_seq whatever the limit: since (where it starts), turns, files (the first 20), files\_total, commands, tests (the newest test run: cmdline, ok or null when unknown, at), last\_said and state (the pane's state now). |
| `untrusted`  | bool      | Always true: the text is the agent's.                                                                                                                                                                                                                                     |

```json
{"id":1,"verb":"agent-activity","params":{"session":"work","window":"build","recap":true}}
```

## `agent-hook-event` <Since verb="agent-hook-event" /> [#agent-hook-event]

Run one harness hook event in the daemon, as tuios agent-hook runs it in a process of its own: the payload is read, the event mapped to the state it reports, and the report made for the pane the caller runs in. The pane is found from the process that sent the call (its TUIOS\_PANE\_ID, or its terminal session and ancestors), never from a param. The result holds what the hook would print for the harness to read. A call that waits on the Inbox for a permission prompt answers when the person does, or when the hold ends.

| Param          | Type   | Required | Default | Description                                                                                                                                                                                                                                                                                                                                              |
| -------------- | ------ | -------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `harness`      | string | yes      |         | The harness whose hook fired, by id or alias, as tuios agent-hook takes it: claude-code, codex, gemini-cli and so on.                                                                                                                                                                                                                                    |
| `event`        | string |          |         | The event, for a harness whose payload does not name it. Omit it when the payload does.                                                                                                                                                                                                                                                                  |
| `payload`      | string |          |         | The hook's JSON payload as the harness wrote it, as a string. Omit it for an event with none.                                                                                                                                                                                                                                                            |
| `payload_json` | object |          |         | The payload as JSON rather than a string, for a caller that cannot quote it. Pass payload or payload\_json, not both.                                                                                                                                                                                                                                    |
| `env`          | object |          |         | The variables of the hook process the mapping reads, by name. Only these are taken: TUIOS\_AGENT, CODEX\_THREAD\_ID, CURSOR\_VERSION, GROK\_SESSION\_ID, CRUSH\_SESSION\_ID. The pane's own variables are always read from the calling process.                                                                                                          |
| `explain`      | bool   |          |         | Also return what was decided and why, as tuios agent-hook --explain prints it.                                                                                                                                                                                                                                                                           |
| `forwarder`    | bool   |          |         | The call comes from the shell line tuios integration installs, which closes its sending half once the call is sent and cannot read JSON. The reply is then the line TUIOS-HOOK-OK and the hook's stdout as it is, with no JSON response, and the connection ends. A hold for the Inbox ends when the caller's process does, not at the end of its input. |

| Result field | Type           | Description                                                                                                                                                                                                                                            |
| ------------ | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `stdout`     | string         | What the hook prints for the harness to read: an empty object for a harness that parses its hook's output as JSON, the lines a session start adds to the agent's context, the line about unread mail, or a permission decision. Empty for most events. |
| `explain`    | object or null | With explain: the decision, the pane it went to and how it was found, what the daemon answered, and any error.                                                                                                                                         |

```json
{"id":1,"verb":"agent-hook-event","params":{"harness":"claude-code","payload":"{\"hook_event_name\":\"UserPromptSubmit\",\"session_id\":\"s1\",\"prompt\":\"fix the build\"}"}}
```

## `agent-mail-notice` <Since verb="agent-mail-notice" /> [#agent-mail-notice]

Answer with one line that tells a pane's agent about its unread mail, once per message. tuios agent-hook calls it for a harness that adds a hook's output to the agent's context. The line holds a count, the senders' names cut to letters, digits and . \_ - : @, and the read-agent-messages command to run. It never holds a subject or a body. A message is announced once: the call marks the unread mail it describes as announced, and the next call answers with an empty notice until newer mail arrives.

| Param              | Type   | Required | Default | Description                                                                                                                                                                                                                                               |
| ------------------ | ------ | -------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `session`          | string |          |         | Session name. Omit from a pane for the pane's own session, and from outside every pane for the most recently active one.                                                                                                                                  |
| `window`           | string |          |         | Window id or name. Omit to target the focused window.                                                                                                                                                                                                     |
| `reset`            | bool   |          | `false` | Announce all unread mail again, also mail announced before. A hook sets it when a conversation starts, resumes or is compacted, since the agent no longer holds the earlier notice.                                                                       |
| `lease`            | bool   |          | `false` | Mark the mail announced for 3 seconds only, and answer with a lease token. The mail is announced for good when the caller sends the token back in commit. A hook that missed its deadline sends nothing back, and the next call announces the mail again. |
| `commit`           | int    |          |         | A lease token from an earlier call. The call then only makes that lease's mail announced for good, and answers with committed.                                                                                                                            |
| `harness`          | string |          |         | Id of the harness whose hook asks. With it the call is held to the guard set-agent-state holds a hook's report to: a pane attributed to another harness, another conversation, or a harness outside the pane gets no notice, and the reason.              |
| `agent_session_id` | string |          |         | The harness's id for the conversation, read as report-agent-activity reads it.                                                                                                                                                                            |
| `harness_pid`      | int    |          |         | The pid of the harness process that ran the hook, read as report-agent-activity reads it.                                                                                                                                                                 |

| Result field | Type   | Description                                                                                                                 |
| ------------ | ------ | --------------------------------------------------------------------------------------------------------------------------- |
| `window_id`  | string | The pane whose mail it is.                                                                                                  |
| `unread`     | int    | How many messages in the pane's inbox are unread, seen ones included.                                                       |
| `notice`     | string | The line to show the agent, empty when there is no unread mail or all of it was announced before.                           |
| `lease`      | int    | The token to send back in commit, for a call with lease that answered with a notice.                                        |
| `committed`  | bool   | For a call with commit: whether the lease was still open and is now announced for good.                                     |
| `reason`     | string | Why the guard gave no notice. Absent when it did not refuse. One of `foreign_session`, `foreign_harness` or `foreign_pane`. |

```json
{"id":1,"verb":"agent-mail-notice","params":{"session":"work","window":"build"}}
```

## `agent-statusline-event` <Since verb="agent-statusline-event" /> [#agent-statusline-event]

Run one status line payload in the daemon, as tuios agent-statusline runs it without --then: the model, context use and cost it names go to the pane the caller runs in, as agent metadata, at most once every 15 seconds while they change. The pane is found from the process that sent the call, never from a param. It prints nothing; a caller with a status line of its own runs that itself.

| Param          | Type   | Required | Default | Description                                                                                                                                                                     |
| -------------- | ------ | -------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `harness`      | string | yes      |         | The harness whose status line ran, such as claude-code.                                                                                                                         |
| `payload`      | string |          |         | The status line payload as the harness wrote it, as a string.                                                                                                                   |
| `payload_json` | object |          |         | The payload as JSON rather than a string. Pass payload or payload\_json, not both.                                                                                              |
| `env`          | object |          |         | The variables of the calling process the mapping reads, by name. Only these are taken: TUIOS\_AGENT, CODEX\_THREAD\_ID, CURSOR\_VERSION, GROK\_SESSION\_ID, CRUSH\_SESSION\_ID. |
| `turn_end`     | bool   |          |         | The harness's turn just ended: changed values go now, whatever the interval, as tuios agent-statusline --turn-end.                                                              |
| `explain`      | bool   |          |         | Also return what was decided and why.                                                                                                                                           |
| `forwarder`    | bool   |          |         | The call comes from the shell line tuios integration installs. The reply is then the line TUIOS-HOOK-OK, with no JSON response, and the connection ends.                        |

| Result field | Type           | Description                                                                      |
| ------------ | -------------- | -------------------------------------------------------------------------------- |
| `sent`       | bool           | Whether the values went to the pane.                                             |
| `skip`       | string         | Why nothing was sent, such as unchanged values or the interval. Empty when sent. |
| `error`      | string         | What went wrong finding the pane or writing to it. Absent when nothing did.      |
| `explain`    | object or null | With explain: the values read, the pane and how it was found.                    |

```json
{"id":1,"verb":"agent-statusline-event","params":{"harness":"claude-code","payload_json":{"model":{"display_name":"Opus"},"context_window":{"used_percentage":42}}}}
```

## `agent-transcript` <Since verb="agent-transcript" /> [#agent-transcript]

Read the conversation of the agent in a pane, for a client that shows it to the person: prompts, answers, thinking, tool calls with their status, diffs of edits, plans and todo lists, decoded from the transcript the pane is joined to. Readers include Claude Code, Codex, Gemini CLI, Qwen Code, Copilot CLI, Amp, OpenCode, Cursor Agent and Pi. Only the person can read it, with a live human\_nonce, as reply-approval checks it. Every string is the agent's or its tools', with control characters removed and likely secrets masked, so the reply is marked untrusted.

| Param         | Type   | Required | Default | Description                                                                                                                                                                                            |
| ------------- | ------ | -------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `session`     | string |          |         | Session name. Omit from a pane for the pane's own session, and from outside every pane for the most recently active one.                                                                               |
| `window`      | string | yes      |         | The pane: a window id or name.                                                                                                                                                                         |
| `human_nonce` | string | yes      |         | The nonce of a client attached now, or of attach-presence on this connection. Without a live one the call is refused with not\_human. A presence made for one session reads only that session's panes. |
| `after`       | string |          |         | The cursor of an earlier reply. The reply then holds the entries after it. Omit it to read the newest limit entries.                                                                                   |
| `before`      | string |          |         | The older cursor of an earlier reply. The reply then holds the newest limit entries before it. Do not give it with after.                                                                              |
| `limit`       | int    |          | `200`   | The most entries to return, 1 to 1000. Leave it out for the default. 0 is refused.                                                                                                                     |
| `image`       | string |          |         | The id of an entry that has an image. The reply then holds that image's media\_type and data (base64) in place of a page. after, before and limit are ignored.                                         |

| Result field | Type      | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------ | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `session`    | string    | The pane's session.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `window`     | string    | The pane's window id.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `harness`    | string    | The harness whose transcript was read.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `cursor`     | string    | Send it as after to read what comes next. It is opaque.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `reset`      | bool      | True when after was not a cursor into the file as it is now. The entries are then the newest limit, and the client starts its list again.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `more`       | bool      | True when a read after a cursor stopped before the end. Read again with the new cursor.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `older`      | string    | Send it as before to read the entries before this page. Empty when the page starts at the first entry.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `entries`    | \[]object | id, at (unix ms), role (user, assistant, tool), kind (text, thinking, tool\_call, tool\_result, plan, todos), text, truncated, tool, target, status (ok, error, running), tool\_id, diff, plan, todos and image. An image's entry has the text \[image] and an image object with its media\_type. Read its data with image set to the entry's id. Each diff line carries spans (syntax tokens with chroma CSS classes) and words (the changed part), in UTF-16 offsets. A diff with whole\_replace true was not matched line by line: each hunk shows the changed old lines removed, then the changed new lines added. An entry with an id the client holds replaces it. |
| `media_type` | string    | With image: image/png, image/jpeg, image/gif or image/webp.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `data`       | string    | With image: the image, base64, at most 10 MiB decoded.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `untrusted`  | bool      | Always true: the text is the agent's.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

```json
{"id":1,"verb":"agent-transcript","params":{"session":"work","window":"api","human_nonce":"<from attach-presence>"}}
```

```json
{"id":2,"verb":"agent-transcript","params":{"session":"work","window":"api","human_nonce":"<from attach-presence>","after":"<the cursor of the last reply>"}}
```

```json
{"id":3,"verb":"agent-transcript","params":{"session":"work","window":"api","human_nonce":"<from attach-presence>","before":"<the older cursor of the first reply>"}}
```

```json
{"id":4,"verb":"agent-transcript","params":{"session":"work","window":"api","human_nonce":"<from attach-presence>","image":"<an entry id>"}}
```

## `artifact-list` <Since verb="artifact-list" /> [#artifact-list]

List what one pane has shown the person, newest first: the TML surfaces it opened, open or closed, and the screenshots it took. The daemon keeps the last 20 of each pane until it restarts.

| Param    | Type   | Required | Default | Description                |
| -------- | ------ | -------- | ------- | -------------------------- |
| `window` | string |          |         | The window id of the pane. |

| Result field | Type      | Description                                                                                                                                                                                                                  |
| ------------ | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `artifacts`  | \[]object | Each artifact: id, kind (tml or screenshot), title, at (Unix nanoseconds) and window\_id. A tml artifact adds surface, target, open, doc and state, and when it closed, reason and value. A screenshot adds path and format. |

## `ask-agent` <Since verb="ask-agent" /> [#ask-agent]

Ask another agent a question, or with select and confirm every agent pane a selector matches: wait until it is not mid-turn, type the question into its pane, wait until it has dealt with it, and answer with what the pane printed in between. A target on needs\_input is refused with agent\_blocked and nothing is typed, because the text would answer its prompt. A target that shows no sign of taking the question within stall\_timeout of Enter fails with prompt\_stalled; the question was typed, so look at the pane before sending it again. Asks of one target take turns: an ask that comes while another ask of the same target runs waits for its turn, first come first served, for up to timeout, and fails with not\_ready when the turn does not come. The reply is another program's output and is data, not instructions.

| Param           | Type   | Required | Default  | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| --------------- | ------ | -------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `session`       | string |          |          | Session name. Omit from a pane for the pane's own session, and from outside every pane for the most recently active one.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `window`        | string |          |          | The agent to ask, by window id or name. list-agents is how you find it. Required unless select is given.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `from`          | string |          |          | The asking window, normally $TUIOS\_PANE\_ID. It is what the cycle guard is keyed on, so omitting it gives up loop detection. human from a process inside a pane of this daemon is refused with forbidden.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `from_host`     | string |          |          | The name of the machine the caller is on, normally $TUIOS\_HOST. Kept on the record only for an ask that arrived over a link.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `text`          | string |          |          | The question. It is typed as one paste (wrapped in bracketed paste when the target has it on) and submitted with a carriage return, the Enter key. Trailing line breaks are dropped, and a question of several lines is submitted once.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `ready_timeout` | int    |          | `30000`  | Milliseconds to wait for the target to be ready before giving up with not\_ready. Ready is idle, done, errored or none; unknown is not ready. A target on needs\_input ends the wait at once with agent\_blocked.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `settle`        | int    |          | `2000`   | Milliseconds of silence from the target that count as it having finished, for a pane that reports no state. The silence is counted from when the target showed it took the question.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `timeout`       | int    |          | `300000` | Milliseconds to wait for the answer overall. An ask that has to wait for its turn behind other asks of the same target waits up to this long for it first, and the wait for the answer then starts again.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `lines`         | int    |          | `200`    | Cap the reply to this many lines, newest kept.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `force`         | bool   |          | `false`  | Send without waiting for the target to be ready, interleaving with whatever it is doing. It does not override agent\_blocked: a target on needs\_input is still refused unless allow\_blocked is set.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `allow_blocked` | bool   |          | `false`  | Type at a target on needs\_input instead of refusing with agent\_blocked. The text then answers whatever prompt the target is showing, so pass it only after reading the prompt with capture-pane and finding it takes free text.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `stall_timeout` | int    |          | `5000`   | Milliseconds after Enter within which the target must show it took the question: its agent state turns working or needs\_input, it finishes a turn, or, for an agent whose harness cannot show working, it prints something. If it shows none of these the ask fails with prompt\_stalled. The question was typed either way.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `select`        | string |          |          | A selector: space-separated key:value terms, all of which must match, each with comma-separated alternatives. Keys: harness (id or program name), state, needs:you, session (glob), group (fan-out group, glob), host (local or a host name, glob), name (window name, glob), cwd (the directory or under it; \~ is home), task (a task card the pane holds, by id, glob), stage (the stage of a card the pane holds), parent and root (the parent agent pane, or the first of its chain, by window id or a start of it). Asks every pane the selector matches at once, at most 16. It reaches agent panes on this machine, in every session, and takes no session and no window. Without confirm nothing is sent: the call fails with confirm\_required, whose hint lists the panes in available and carries the token in confirm. |
| `confirm`       | string |          |          | The token for the set of panes the selector matches, from a confirm\_required hint or from list-agents with the same selector. The write goes ahead only when the selector still matches exactly that set; otherwise it fails with confirm\_required again and the new set.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

| Result field     | Type      | Description                                                                                                                                                                                                                                                                                    |
| ---------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `replies`        | \[]object | With select: one row per pane, in session order: session, window, name, ok, and the fields of a single ask's answer when it was answered, or error (code, message, hint) when it was not. A pane on needs\_input is refused in its row with agent\_blocked unless allow\_blocked is set.       |
| `answered`       | int       | With select: how many panes answered.                                                                                                                                                                                                                                                          |
| `failed`         | int       | With select: how many did not.                                                                                                                                                                                                                                                                 |
| `window`         | string    | The window that was asked.                                                                                                                                                                                                                                                                     |
| `waited_for`     | string    | The state the target was in when the question was sent.                                                                                                                                                                                                                                        |
| `queued_behind`  | int       | How many asks of the same target were ahead of this one when it came. 0 when it did not wait for a turn.                                                                                                                                                                                       |
| `waited_turn_ms` | int       | How long the ask waited for its turn, in milliseconds.                                                                                                                                                                                                                                         |
| `settled_by`     | string    | What ended the wait: agent-state when the target reported it had finished, idle when it simply went quiet, timeout when neither happened, or window-closed/session-closed when the target went away. One of `agent-state`, `idle`, `timeout`, `window-closed`, `session-closed` or `shutdown`. |
| `state`          | string    | The target's agent state after answering.                                                                                                                                                                                                                                                      |
| `untrusted`      | bool      | Always true. The reply is another program's output.                                                                                                                                                                                                                                            |
| `reply`          | string    | What the pane printed after the question was sent.                                                                                                                                                                                                                                             |
| `lines`          | int       | How many lines the reply holds.                                                                                                                                                                                                                                                                |
| `truncated`      | bool      | Whether older reply lines were cut to fit the line cap.                                                                                                                                                                                                                                        |

```json
{"id":1,"verb":"ask-agent","params":{"session":"work","window":"review","from":"$TUIOS_PANE_ID","text":"does the payment retry path look right to you?"}}
```

```json
{"id":1,"verb":"ask-agent","params":{"select":"group:fan/add-retry state:idle","text":"summarise your change in one line"}}
```

## `ask-human` <Since verb="ask-human" /> [#ask-human]

Ask the person a question with a fixed set of answers, and wait for the answer. The question goes in the Inbox as an ask item; a client that shows the asking pane opens it at once, and a detached session keeps it for the next attach. When the wait ends first the status is pending and the question stays: the answer is then mailed to the asking pane from human, marked verified\_human, or read by calling again with request\_id. A caller inside a pane asks only as that pane. Refused over a link.

| Param        | Type      | Required | Default  | Description                                                                                                                                                                       |
| ------------ | --------- | -------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `session`    | string    |          |          | Session name. Omit from a pane for the pane's own session, and from outside every pane for the most recently active one.                                                          |
| `window`     | string    |          |          | The pane asking, where a late answer is mailed. Omit to ask as your own pane from inside one, or as no pane from outside every pane. A caller inside a pane may not name another. |
| `question`   | string    |          |          | The question: one line of printable text, at most 160 bytes, which the Inbox shows as written. Required unless request\_id is given.                                              |
| `options`    | \[]string |          |          | The answers, 1 to 9, picked with the keys 1 to 9. Each is one line of printable text, at most 60 bytes, and no two are the same. Required unless request\_id is given.            |
| `timeout`    | int       |          | `120000` | Milliseconds to wait for the answer, at most one hour. The question outlives the wait.                                                                                            |
| `wait`       | bool      |          | `true`   | Wait for the answer. Pass false to ask and return pending at once.                                                                                                                |
| `request_id` | string    |          |          | Come back for a question already asked: wait on it again, or read how it ended. Takes no question or options.                                                                     |

| Result field     | Type   | Description                                                                                                                                                             |
| ---------------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `request_id`     | string | The question's id: pass it back to wait again or read the answer.                                                                                                       |
| `status`         | string | answered, pending (the wait ended first; the question stays), dismissed, superseded (the pane asked a newer one), window\_closed, session\_closed, evicted or shutdown. |

## `set-pane-grants` <Since verb="set-pane-grants" /> [#set-pane-grants]

Give a pane grants, or with reset the default of \[agents.permissions]. Grants are read (its own session and fan group), write (type into its own session), fan (write in its fan group and start agents), respond (answer prompts without the person's nonce) and admin (everything else, as before grants existed). From outside every pane anything may be given. A pane may change only its own grants unless it holds admin, and may never give more than it holds, so a pane cannot widen itself. Refused over a link.

| Param     | Type      | Required | Default | Description                                                                                                                     |
| --------- | --------- | -------- | ------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `session` | string    |          |         | Session of the pane. Omit from a pane for the pane's own session, and from outside every pane for the most recently active one. |
| `window`  | string    |          |         | The pane, by window id or name. Omit from a pane to mean the caller's own.                                                      |
| `grants`  | \[]string |          |         | The grants to give, or none for no grants at all. One of `read`, `write`, `fan`, `respond`, `files`, `task`, `admin` or `none`. |
| `reset`   | bool      |          | `false` | Give the pane the default of \[agents.permissions] instead of grants of its own.                                                |

| Result field        | Type      | Description                                                                           |
| ------------------- | --------- | ------------------------------------------------------------------------------------- |
| `session`           | string    | The pane's session.                                                                   |
| `window`            | string    | The pane's window id.                                                                 |
| `grants`            | \[]string | What the pane holds now.                                                              |
| `explicit`          | bool      | False after reset: the pane holds the default and follows it when the config changes. |
| `previous`          | \[]string | What the pane held before.                                                            |
| `previous_explicit` | bool      | Whether what it held before was its own.                                              |

## `start-agent` <Since verb="start-agent" /> [#start-agent]

A pane on needs\_input ends the wait at once with ready false and blocked\_by, and is kept. With prompt, the first prompt is typed once it is ready, the way fan types it. A named session that does not exist is created. From another machine, address it with a host-qualified session and name the repository by repo\_url.
