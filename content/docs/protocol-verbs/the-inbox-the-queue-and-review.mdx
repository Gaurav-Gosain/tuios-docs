## `add-reply-history` <Since verb="add-reply-history" /> [#add-reply-history]

Keep a message the person sent to an agent in the reply history. The same message again moves to the end. A message keeps at most 256 KiB of pastes and images: past that the largest are dropped and named. Only the person adds to it, with a live human\_nonce.

| Param         | Type      | Required | Default | Description                                                                                                                       |
| ------------- | --------- | -------- | ------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `target`      | string    | yes      |         | The key the client keeps the history under.                                                                                       |
| `parts`       | \[]object | yes      |         | The message, as queue-prompt takes it.                                                                                            |
| `human_nonce` | string    |          |         | The nonce from the attach reply of a client attached now. The TUI sends its own. Without a live one the call is not the person's. |

| Result field | Type      | Description                   |
| ------------ | --------- | ----------------------------- |
| `dropped`    | \[]string | The blocks too large to keep. |

```json
{"id":1,"verb":"add-reply-history","params":{"target":"claude-code:/work/api","parts":[{"kind":"text","text":"rerun with -count=1"}],"human_nonce":"<from the attach reply>"}}
```

## `answer-ask` <Since verb="answer-ask" /> [#answer-ask]

Answer an ask-human question for the person. Only a client attached right now can, with the nonce from its attach reply: an agent never can. The answer must be one of the question's options. The first answer wins; a later one is answered with the one that stands and applied false.

| Param            | Type   | Required | Default | Description                                                                                                                                                                                 |
| ---------------- | ------ | -------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `request_id`     | string |          |         | The request\_id of the ask item.                                                                                                                                                            |
| `answer`         | string |          |         | One of the item's options.                                                                                                                                                                  |
| `human_nonce`    | string |          |         | The nonce the daemon issued in an attach reply, for a client attached now over the same kind of connection. The TUI sends its own.                                                          |
| `question`       | string |          |         | The question the answer was picked from. When given and it is not the item's, nothing is answered: applied is false with reason changed. The TUI always sends it.                           |
| `upgrade_dialog` | bool   |          |         | The answer is a key pressed in a client's live upgrade dialog. A live upgrade's ask takes only an answer that carries it. The TUI sends it from that dialog alone, and gui-bridge drops it. |

| Result field  | Type   | Description                                                             |
| ------------- | ------ | ----------------------------------------------------------------------- |
| `request_id`  | string | The question answered.                                                  |
| `answer`      | string | The answer that stands: this one when applied, an earlier one when not. |
| `applied`     | bool   | False when an earlier answer stands or the question changed.            |
| `reason`      | string | answered, or how the question ended before this answer, or changed.     |
| `answered_by` | string | The id of the client whose answer stands.                               |

```json
{"id":1,"verb":"answer-ask","params":{"request_id":"9f86d081884c7d65","answer":"yes","human_nonce":"<from the attach reply>"}}
```

## `cancel-queued` <Since verb="cancel-queued" /> [#cancel-queued]

Drop messages from a pane's delivery queue before they are typed. The person, with a live human\_nonce, may drop any entry; a pane only the entries it queued; a linked machine only the entries it queued; a caller outside every pane every entry but the person's. An entry being typed cannot be dropped. Dropping a stalled entry closes its Inbox question; the entries behind it are typed at the pane's next rest, one reached after the stalled entry was typed. A linked machine that gave no name drops only what it queued on the same connection.

| Param         | Type   | Required | Default | Description                                                                                                                                                                                                                          |
| ------------- | ------ | -------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `session`     | string |          |         | Session name. Omit from a pane for the pane's own session, and from outside every pane for the most recently active one.                                                                                                             |
| `window`      | string |          |         | Window id or name. With all, omit it to target the focused window. With id, omit it to find the entry in any pane of the session.                                                                                                    |
| `id`          | string |          |         | The entry to drop.                                                                                                                                                                                                                   |
| `all`         | bool   |          | `false` | Drop every entry of the window the caller may drop.                                                                                                                                                                                  |
| `human_nonce` | string |          |         | The attached client's nonce, to drop as the person. One that does not verify is refused with not\_human.                                                                                                                             |
| `host`        | string |          |         | A machine from \[hosts]: drop from a pane's queue there, over the link. The link drops only the entries this machine queued there. Only a caller outside every pane may ask; the far machine's policy for this one must allow write. |

| Result field | Type      | Description                                  |
| ------------ | --------- | -------------------------------------------- |
| `cancelled`  | \[]string | The entries dropped.                         |
| `queued`     | int       | How many entries the pane's queue holds now. |

```json
{"id":1,"verb":"cancel-queued","params":{"session":"work","window":"build","all":true}}
```

```json
{"id":1,"verb":"cancel-queued","params":{"session":"work","id":"q3"}}
```

| Result field | Type      | Description                                                                                                                                                                                                                                                     |

## `dismiss-attention` <Since verb="dismiss-attention" /> [#dismiss-attention]

Close one Inbox item for the person. Only a client attached right now can do it, with the nonce from its attach reply: an agent cannot clear what is waiting for the person. Dismissing a finished item marks the pane's turns seen, and dismissing mail marks the person's mail in the thread read. An item of a linked host is hidden on this daemon only, until that host changes it; nothing on that host is marked.

| Param         | Type   | Required | Default | Description                                                                                                                        |
| ------------- | ------ | -------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `id`          | string |          |         | The item id list-attention printed.                                                                                                |
| `human_nonce` | string |          |         | The nonce the daemon issued in an attach reply, for a client attached now over the same kind of connection. The TUI sends its own. |

| Result field | Type   | Description                                                                                                               |
| ------------ | ------ | ------------------------------------------------------------------------------------------------------------------------- |
| `id`         | string | The item that was closed.                                                                                                 |
| `kind`       | string | Its kind. One of `approval`, `plan`, `ask`, `question`, `mail`, `errored`, `resume`, `finished`, `outbox` or `held_mail`. |
| `session`    | string | Its session.                                                                                                              |
| `host`       | string | The linked host the item came from. Omitted for this machine.                                                             |
| `dismissed`  | bool   | Always true on success.                                                                                                   |


## `queue-prompt` <Since verb="queue-prompt" /> [#queue-prompt]

Queue a message for the agent in a pane, typed as a prompt once the agent has been at rest for a second, and never over a prompt it is waiting on. One entry is typed per rest, and the prompt gate waits for the agent to show it took it; an entry it did not take is marked stalled, never typed again, and opens an Inbox question. A queue holds at most \[agents.queue] max messages, and dies with the daemon, the pane, or the agent leaving the pane. It types into the pane, so a pane may queue only for a pane that holds nothing it does not, and its entry is checked against its grants again when it is typed. Who queued it (by) comes from the connection: human only with a live human\_nonce, the pane's id for a pane, link:HOST over a link, shell otherwise.

## `review-stage` <Since verb="review-stage" /> [#review-stage]

Stage or unstage a change in the worktree of a pane. Name a whole file, one hunk, or some lines of a hunk. Only the index changes. The working files do not change. Every result carries an undo object. Send it back with action undo to undo the call. The undo result carries its own undo object, which redoes the call.

| Param         | Type   | Required | Default | Description                                                                                                                                  |
| ------------- | ------ | -------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `action`      | string | yes      |         | What to do. One of `stage`, `unstage` or `undo`.                                                                                             |
| `session`     | string |          |         | Session name. Omit from a pane for the pane's own session, and from outside every pane for the most recently active one.                     |
| `window`      | string |          |         | Window id or name. Omit to target the focused window.                                                                                        |
| `path`        | string |          |         | The file, relative to the repository root. Needed to stage and unstage.                                                                      |
| `hunk`        | string |          |         | The hunk header, exactly as review-diff returned it. Stage reads it from index unstaged, unstage from index staged. Omit for the whole file. |
| `lines`       | \[]int |          |         | Indices into the lines of the hunk. Only added and removed lines count. Context lines are ignored. Omit for the whole hunk.                  |
| `context`     | int    |          | `3`     | The context of the diff the hunk came from, 0 to 20. It must match that diff.                                                                |
| `undo`        | object |          |         | For action undo: the undo object of the result to undo, with entries and after.                                                              |
| `human_nonce` | string |          |         | The nonce from the attach reply of a client attached now. The TUI sends its own. Without a live one the call is not the person's.            |

| Result field | Type   | Description                                                                                                                                                                               |
| ------------ | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `session`    | string | The session of the pane.                                                                                                                                                                  |
| `window`     | string | The pane, by id.                                                                                                                                                                          |
| `worktree`   | string | The worktree whose index changed.                                                                                                                                                         |
| `path`       | string | The file named.                                                                                                                                                                           |
| `action`     | string | The action done: stage, unstage or undo.                                                                                                                                                  |
| `undo`       | object | entries: the index entries of the paths touched before the call, each path with mode and sha, or absent. after: the same paths after the call. Send it with action undo to undo the call. |


## `send-review` <Since verb="send-review" /> [#send-review]

Send a pane's unsent review notes to its agent as one message, through the delivery queue: typed now when the agent is at rest, else when it next comes to rest. The message says it is from the person only with a live human\_nonce, and labels each note written by someone other than the sender with its author. It types into the pane, so a pane may send only to a pane that holds nothing it does not, and a note whose author may not type there now is withheld.

| Param         | Type      | Required | Default | Description                                                                                                                       |
| ------------- | --------- | -------- | ------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `session`     | string    |          |         | Session name. Omit from a pane for the pane's own session, and from outside every pane for the most recently active one.          |
| `window`      | string    |          |         | Window id or name. Omit to target the focused window.                                                                             |
| `ids`         | \[]string |          |         | Only these notes. Omit for every unsent one.                                                                                      |
| `now`         | bool      |          | `false` | Type it now or not at all: refuse with agent\_blocked or not\_ready instead of queueing.                                          |
| `human_nonce` | string    |          |         | The nonce from the attach reply of a client attached now. The TUI sends its own. Without a live one the call is not the person's. |

| Result field      | Type      | Description                                                                                                                                                                 |
| ----------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `notes`           | int       | How many notes the message carries.                                                                                                                                         |
| `ids`             | \[]string | The notes sent, now marked with sent\_at.                                                                                                                                   |
| `queued_id`       | string    | The queue entry, which cancel-queued takes.                                                                                                                                 |
| `position`        | int       | Its place in the pane's queue, 1 for next.                                                                                                                                  |
| `queued`          | int       | How many messages the pane's queue holds now.                                                                                                                               |
| `delivering`      | bool      | The message is next and the agent is at rest, so it is typed within about a second.                                                                                         |
| `withheld`        | \[]string | Notes left out, not sent and not marked: their author (a pane, or a linked machine) may not type into this pane now, or the pane that wrote them is gone. Absent when none. |
| `withheld_reason` | string    | Why the first withheld note was left out. Absent when none.                                                                                                                 |

```json
{"id":1,"verb":"send-review","params":{"session":"work","window":"build","human_nonce":"<from the attach reply>"}}
```
