---
title: Command Finder
description: Find a tuios command by what you want to do, with its usage line, its flags and a link to its section of the CLI reference, read from tuios's own command tree.
icon: SquareTerminal
---

Type what you want to do, a part of a command's name, or a flag such as `--json`. A command whose name has your words comes first. Open the flags of a command to see them all, and follow "reference" to its section of the [CLI Reference](/docs/cli-reference).

<CommandFinder />

The list comes from tuios itself: `tuios help --json`, turned into data by `scripts/commands.mjs`. So a usage line or a flag here is the one the binary has.

In a terminal, `tuios help -i` opens the same list with a search, and `tuios COMMAND --help` prints one command whole.
