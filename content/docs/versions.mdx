This page lists what each tuios version added. The docs mark the same things with a badge:

- <Since command="pair" /> means the feature is on tuios main and in no release yet. Build tuios from main to use it.
- <Since config="keybindings.option_glyphs" /> means the feature is in that release and every later one.

A badge for a version older than v0.8.0 is not shown, because most keys came before it. The list below has every version.

## How the list is made

A script reads the tuios repository. For each config key, command, keybinding action and protocol verb on main, it finds the first release tag whose source has it:

- **Config keys:** the paths of the config structs in `internal/config`.
- **Commands:** the `tuios` command tree, and the `Use:` lines in `cmd/tuios`.
- **Keybinding actions:** the action names in `internal/config`.
- **Protocol verbs:** the verb names in `internal/session`.

A few features have no key of their own, such as the seen state of mail. Each one has a probe string in `lib/since/features.json`. A version is the first tag that has the key, so a key that tuios renamed shows the version of the new name.
