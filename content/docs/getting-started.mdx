This page takes you from nothing to a working session in about five minutes.

You need a terminal with true color support. A [Nerd Font](https://www.nerdfonts.com) makes the icons render; without one, start TUIOS with `--ascii-only`.

## Install

<Tabs items={['Homebrew', 'Arch (AUR)', 'Script', 'Nix', 'Go', 'Docker']}>
<Tab value="Homebrew">
macOS and Linux:

```bash
brew tap Gaurav-Gosain/tap
brew install tuios
```
</Tab>
<Tab value="Arch (AUR)">
```bash
yay -S tuios-bin
```
</Tab>
<Tab value="Script">
Linux and macOS. Installs the `tuios` binary into `/usr/local/bin`, `~/.local/bin` or `~/bin`, whichever it can write to.

```bash
curl -fsSL https://raw.githubusercontent.com/Gaurav-Gosain/tuios/main/install.sh | bash
```
</Tab>
<Tab value="Nix">
```bash
nix run github:Gaurav-Gosain/tuios#tuios
```

The flake builds for `x86_64-linux`, `aarch64-linux` and `aarch64-darwin`. On an Intel Mac, use a release binary.
</Tab>
<Tab value="Go">
Needs Go 1.26 or newer.

```bash
go install github.com/Gaurav-Gosain/tuios/cmd/tuios@latest
```
</Tab>
<Tab value="Docker">
```bash
docker run -it --rm ghcr.io/gaurav-gosain/tuios:latest
```
</Tab>
</Tabs>

Pre-built binaries for Linux, macOS, Windows and FreeBSD are on the [releases page](https://github.com/Gaurav-Gosain/tuios/releases).

Check the install:

```bash
tuios --version
```

The first line names the version and the terminal emulator backend the binary was built with, for example `tuios version 0.7.0 [pure-Go backend]`.

<Callout type="info" title="Keeping it up to date">
If you installed with the script or a release binary, `tuios update` installs the newest release over the binary (`tuios update --check` only reports). For Homebrew, AUR, Nix and Go installs, use that tool to update. `tuios update` detects them and prints the right command instead.
</Callout>

The browser terminal is a separate binary, `tuios-web`. See [Web Terminal](/docs/web) to install it.

### Build from source

```bash
git clone https://github.com/Gaurav-Gosain/tuios.git
cd tuios
go build -o tuios ./cmd/tuios
```

`./scripts/install.sh` builds and installs into `~/.local/bin`. It defaults to the libghostty-vt emulator backend, which needs `zig`. Run `./scripts/install.sh pure` for the pure Go emulator, which needs nothing beyond Go.

## Your first session

<Steps>

<Step>

### Start TUIOS

```bash
tuios
```

The first run creates a session called `session-0` and shows a welcome screen with four keys on it:

<TerminalCapture
  title="tuios"
  rows={5}
  lines={[
    { text: '  TUIOS' },
    { text: '  Terminal UI Operating System', tone: 'dim' },
    { text: '' },
    { text: '  n  new window    N  new session    ?  help    ,  settings' },
  ]}
/>

You are in **window management mode**. Keys here arrange windows. Nothing is sent to a shell yet.

</Step>

<Step>

### Open a window

Press <kbd>n</kbd>. A window opens with your shell in it.

</Step>

<Step>

### Type in it

Press <kbd>i</kbd> (or <kbd>Enter</kbd>) to enter **terminal mode**. Your keys now go to the shell. Run a command:

```bash
ls
```

</Step>

<Step>

### Go back to window management

Press <kbd>Alt</kbd>+<kbd>Esc</kbd> (<kbd>Opt</kbd>+<kbd>Esc</kbd> on macOS), or <kbd>Ctrl</kbd>+<kbd>B</kbd> then <kbd>Esc</kbd>.

A bare <kbd>Esc</kbd> stays in terminal mode and goes to the program, so vim and other full-screen programs keep working.

</Step>

<Step>

### Open two more windows

Press <kbd>n</kbd> twice. Tiling is on by default, so each new window takes half of the focused one and all three stay visible.

Move between them with <kbd>Tab</kbd> and <kbd>Shift</kbd>+<kbd>Tab</kbd>, the number keys <kbd>1</kbd> to <kbd>9</kbd>, or <kbd>Alt</kbd>+arrow keys to move to the neighbour in that direction. You can also click a window.

</Step>

<Step>

### Try another workspace

Press <kbd>Alt</kbd>+<kbd>2</kbd> (<kbd>Opt</kbd>+<kbd>2</kbd> on macOS) to switch to workspace 2. It is empty. Open a window there, then press <kbd>Alt</kbd>+<kbd>1</kbd> to go back.

</Step>

<Step>

### Detach, and come back

Press <kbd>Ctrl</kbd>+<kbd>B</kbd> then <kbd>d</kbd>. TUIOS exits, but the session and its shells keep running in the background daemon. Run `tuios` again and everything is where you left it.

</Step>

</Steps>

<Callout type="tip" title="When you forget a key">
Press <kbd>Ctrl</kbd>+<kbd>P</kbd> in either mode to open the command palette and search every command by name. Press <kbd>Ctrl</kbd>+<kbd>B</kbd> and wait half a second: a panel lists every key the prefix accepts next. <kbd>Ctrl</kbd>+<kbd>B</kbd> then <kbd>?</kbd> opens the full help.
</Callout>

## The two modes

| Mode | What your keys do | How to get there |
|------|-------------------|------------------|
| Window management | Create, close, move, tile and switch windows | <kbd>Alt</kbd>+<kbd>Esc</kbd>, or <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>Esc</kbd> |
| Terminal | Go to the program in the focused window | <kbd>i</kbd> or <kbd>Enter</kbd> |

<kbd>Ctrl</kbd>+<kbd>B</kbd> is the **prefix** key. It works in both modes: press it, release it, then press the next key. You can change it with `keybindings.leader_key` in the [configuration](/docs/configuration).

## Keys for day one

On macOS, read <kbd>Alt</kbd> as <kbd>Opt</kbd>. If an <kbd>Opt</kbd> chord types a strange character instead, see the [macOS notes](/docs/keybindings#macos).

**Windows**

| Key | Action |
|-----|--------|
| <kbd>n</kbd> | New window (window mode) |
| <kbd>w</kbd> or <kbd>x</kbd> | Close the focused window (window mode) |
| <kbd>r</kbd> | Rename the focused window (window mode) |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Next / previous window (window mode) |
| <kbd>Alt</kbd>+<kbd>N</kbd> / <kbd>Alt</kbd>+<kbd>P</kbd> | Next / previous window (both modes) |
| <kbd>Alt</kbd>+arrow | Focus the window in that direction (both modes) |
| <kbd>1</kbd> to <kbd>9</kbd> | Focus window by number (window mode) |
| <kbd>z</kbd> | Zoom the focused window to fill the screen, and back (window mode) |
| <kbd>m</kbd> | Minimize to the dock (window mode). <kbd>M</kbd> restores all. |

The prefix versions work in both modes: <kbd>Ctrl</kbd>+<kbd>B</kbd> then <kbd>c</kbd> (new), <kbd>x</kbd> (close), <kbd>r</kbd> (rename), <kbd>n</kbd>/<kbd>p</kbd> (next/previous), an arrow key (focus that way), <kbd>0</kbd> to <kbd>9</kbd> (focus by number), <kbd>z</kbd> (zoom).

**Tiling**

| Key | Action |
|-----|--------|
| <kbd>t</kbd> or <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>Space</kbd> | Turn tiling on or off |
| <kbd>-</kbd> / <kbd>\|</kbd> | Split the focused window: new window below / to the right (window mode) |
| <kbd>H</kbd> <kbd>J</kbd> <kbd>K</kbd> <kbd>L</kbd> | Swap with the neighbour left / down / up / right (window mode) |
| <kbd>=</kbd> | Make all splits equal (window mode) |

[BSP Tiling](/docs/bsp-tiling) covers preselection, resizing and the other layouts.

**Workspaces**

| Key | Action |
|-----|--------|
| <kbd>Alt</kbd>+<kbd>1</kbd> to <kbd>9</kbd> | Switch to workspace 1 to 9 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>1</kbd> to <kbd>9</kbd> | Move the focused window there, and follow it |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>w</kbd>, then a digit | Switch workspace from the prefix menu |

<kbd>Ctrl</kbd>+<kbd>B</kbd> followed directly by a digit focuses a **window**, not a workspace.

**Scrollback and copying**

| Key | Action |
|-----|--------|
| Mouse wheel | Scroll the window's history. Typing, or scrolling back to the bottom, returns to live output. |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>[</kbd> | Enter copy mode: move with vim keys, <kbd>/</kbd> to search, <kbd>v</kbd> to select, <kbd>y</kbd> to copy, <kbd>Esc</kbd> to leave |
| Drag with the mouse | Select text. It is copied when you release. |

**Everything else**

| Key | Action |
|-----|--------|
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Command palette |
| <kbd>Alt</kbd>+<kbd>Space</kbd> or <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>a</kbd> | App launcher: start any program on your `$PATH` in a new window |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>S</kbd> | Session switcher |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>,</kbd> | Settings page (<kbd>,</kbd> in window mode) |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>?</kbd> | Help (<kbd>?</kbd> in window mode) |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>d</kbd> | Detach, leaving the session running |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>q</kbd> | Quit menu: detach, switch session, or kill this session |

The full list is on the [Keybindings](/docs/keybindings) page, and `tuios keybinds list` prints the bindings in effect on your machine.

## Sessions

`tuios` on its own attaches to your most recent session, and creates one if there is none. To manage several:

```bash
tuios new work          # create a session called "work" and attach to it
tuios ls                # list sessions
tuios attach work       # attach to "work"
tuios kill-session work # end "work" and every window in it
```

Inside TUIOS, <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>S</kbd> switches between sessions and <kbd>N</kbd> (window mode) creates one.

If you want a session that lives and dies with this terminal and starts no daemon, run `tuios --standalone`. [Sessions](/docs/sessions) explains both kinds and exactly what survives a restart.

## Make it yours

```bash
tuios config edit        # open the config file in $EDITOR
tuios config path        # print where it is
tuios --list-themes      # list the built-in themes
tuios --theme dracula    # start with a theme
```

Most settings can also be changed live on the settings page, <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>,</kbd>. See [Configuration](/docs/configuration) for every option.

## Shell completions

```bash
# Bash
tuios completion bash > /etc/bash_completion.d/tuios

# Zsh
tuios completion zsh > "${fpath[1]}/_tuios"

# Fish
tuios completion fish > ~/.config/fish/completions/tuios.fish

# PowerShell
tuios completion powershell > tuios.ps1
```
