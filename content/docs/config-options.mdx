Every option that `tuios set-config` takes, in one list you can filter. Type part of a name, a word of a description, or a value such as `rounded`. The section menu and the type chips narrow the list. The copy button gives the `tuios set-config` line for the option at its default, ready to edit.

<OptionExplorer />

The list comes from tuios itself: `tuios list-options --json` on a fresh config, turned into data by `scripts/options.mjs`. So a type, a default or an accepted value here is the one tuios checks, not a copy that can drift.

## Set an option

```bash
tuios set-config appearance.border_style rounded    # apply it now, and save it
tuios get-config appearance.border_style --json      # what it is, and where it came from
tuios list-options --search "pane bg"                # the same search, in a session
```

An `[appearance]` option also answers to its bare name, so `tuios set-config border_style rounded` works. `set-config --no-save` applies a value for this client only. See [set-config](/docs/cli-reference#set-config).

<Callout title="Not every table is here">
`[keybindings]`, `[hooks]`, `[hosts]`, `[tailscale]`, the `[agents]` tables and the `[dock]` lists are written in `config.toml`, not with `set-config`. [Configuration](/docs/configuration) has each of them. [Keybindings](/docs/keybindings) has a filterable list of every default key.
</Callout>

Old keys, such as `appearance.animations_enabled`, are hidden unless you tick Show old keys. TUIOS still reads them and folds each into the key that replaced it, which the row names.
