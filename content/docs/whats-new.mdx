## Also new

- **Less memory for long histories.** A full scrollback ring now reuses each slot at the size of its line, instead of growing busy slots to twice their size. The live heap after a flood of ten times the history, pure Go backend:

  | Panes x history | Before | After |
  |---|---|---|
  | 9 x 10,000 | 28.1 MB | 19.2 MB |
  | 50 x 10,000 | 149.3 MB | 99.9 MB |
  | 9 x 100,000 | 218.5 MB | 129.1 MB |
  | 50 x 100,000 | 1,208 MB | 711 MB |

- **Presets and Any machine.** `[agents.presets.NAME]` starts one kind of agent with one flag, and the New agent sheet can let the daemon pick the machine with the most room. See [Starting an Agent](/docs/new-agent#presets).
- **Mail receipts.** `read-agent-messages --sent` shows whether each message was delivered, seen or read, and mail that waits for a link says why, on both machines. See [Agent Messaging](/docs/agent-messaging#did-my-mail-arrive).
- **One command on another machine.** `tuios run --host build -- uname -a` runs a line there with no pane. See [Remote Hosts](/docs/remote-hosts#run-on-a-host).
- **Pictures and emoji.** Kitty graphics pictures draw as block characters on a terminal without graphics, and screenshots draw colour emoji and emoji sequences. See [Images Without Graphics](/docs/images-without-graphics#kitty-graphics-pictures) and [Screenshots](/docs/screenshots#emoji).
- **Motion on your terms.** `[motion]` turns each motion on or off and times it, and a workspace switch can slide or fade. See [Configuration](/docs/configuration#each-motion).
- **Keys.** Menus of your own open over the rail and the Inbox too, <kbd>Enter</kbd> leaves copy mode, <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>m</kbd> <kbd>f</kbd> minimizes every other pane, and the leader takes the character an Option chord types on a German Mac. See [Keybindings](/docs/keybindings#menus-nested-under-the-leader).
- **Layout without a client.** `split-window`, `zoom-window`, `swap-window`, `resize-window` and `move-window` work on a session no client shows. See [CLI Reference](/docs/cli-reference#zoom-window).
- **Login shells.** `[shell] login = true` starts each new pane as a login shell, so a `PATH` set in `.zprofile` is there. See [Login shells](/docs/configuration#login-shells).
- **The client follows a live upgrade.** After `tuios daemon upgrade` to a newer build, the client on this machine runs the new build too, on the same terminal. See [Upgrade in place](/docs/daemon-restart#upgrade-in-place).
- **The reply editor.** Select with the mouse or with <kbd>Shift</kbd>, copy and cut, send now with <kbd>Alt</kbd>+<kbd>Enter</kbd> while the agent works, and see each sent reply in the thread with its state. `[agents] reply_rows` sets its height. See [The reply editor](/docs/agent-inbox#the-reply-editor).
- **Layouts from the daemon.** `tuios layout save` and `tuios layout load` work with no client, and the picker lists the templates of the machine the session is on. See [Layout templates](/docs/bsp-tiling#layout-templates).
- **Smaller things.** Ask before closing a pane (`appearance.confirm_close`), link rules that turn ticket IDs into links, a setup command for new worktrees, keep the machine awake while agents work, the daemon as a login service, and a log line that says why each pane went.

Every option, with its default and the version that added it, is in the [Option Explorer](/docs/config-options).

## When you upgrade

[Upgrading to v0.13.0](/docs/upgrading-to-v0-13-0) has every change to check. In short:

- **Cell frames.** They are the default. If the screen looks wrong, set `appearance.cell_frames = "off"`. See [How frames reach the terminal](/docs/configuration#cell-frames).
- **Action names.** Each action has one name now. The older names still work. See [Older action names](/docs/keybindings#older-action-names).
- **Usage limits.** An agent stopped on a usage limit is `limit_reached`, not `errored`. See [A usage limit](/docs/agents#usage-limit).
- **Mermaid.** The rarer diagram types moved to the `sketch` plugin. Eight common types still draw in tuios. For the rest, run `tuios plugins install sketch`.
- **Shell marks.** bash and zsh panes now get OSC 133 prompt marks. Set `[shell] integration = "off"` to start shells as before.
- **ghostty backend.** It now uses libghostty-vt 1.0. Rebuild it with `scripts/install.sh ghostty`.
- **The daemon.** Move a running daemon to the new build with `tuios daemon upgrade`. Your panes keep their programs. See [Upgrade in place](/docs/daemon-restart#upgrade-in-place).

The [release notes](/releases) list every change.
