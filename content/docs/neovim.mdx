Neovim works in a tuios pane with no plugin. Two community plugins make it work better with tuios:

- [tuios-nvim-navigator](#move-between-splits-and-panes) lets the same keys move through Neovim splits and tuios panes.
- [tuios-look-sync.nvim](#follow-your-look) gives Neovim the colours of the theme that tuios shows.

<Callout>
tuios answers light and dark reports, so Neovim sets `'background'` correctly without a plugin. See [Light and dark reports](/docs/themes#light-and-dark-reports) on the themes page.
</Callout>

## Move between splits and panes

[tuios-nvim-navigator](https://github.com/Tim4c/tuios-nvim-navigator) moves focus through Neovim splits first. At the edge of the last split, tuios moves focus to the next pane in that direction.

Install it with lazy.nvim:

```lua
{
  "Tim4c/tuios-nvim-navigator",
  config = function()
    require("tuios-nvim-navigator").setup()
  end,
}
```

Turn the feature on in tuios. It is off by default.

```toml
[appearance]
nvim_navigation = true
```

The default keys are <kbd>Alt</kbd>+<kbd>←</kbd>, <kbd>Alt</kbd>+<kbd>↓</kbd>, <kbd>Alt</kbd>+<kbd>↑</kbd> and <kbd>Alt</kbd>+<kbd>→</kbd> in Neovim normal mode. tuios uses the same keys in terminal mode. If you change the keys on one side, change the other side to match.

In shells and other programs, the keys keep their normal tuios action. For the messages the plugin sends and the rules tuios applies, see [Neovim pane navigation](/docs/keybindings#neovim-pane-navigation).

[Tim4c](https://github.com/Tim4c) wrote and maintains [tuios-nvim-navigator](https://github.com/Tim4c/tuios-nvim-navigator). Report problems with the plugin in its repository.

## Follow your look

[tuios-look-sync.nvim](https://github.com/nkapila6/tuios-look-sync.nvim) builds a base16 colorscheme from the theme that tuios shows. When you apply a look with `tuios look apply`, Neovim changes its colours to match. It needs Neovim 0.10 or later and mini.base16.

For the lazy.nvim snippet and the limits, see [Neovim: follow your look](/docs/themes#neovim-look-sync) on the themes page.

[nkapila6](https://github.com/nkapila6) wrote and maintains [tuios-look-sync.nvim](https://github.com/nkapila6/tuios-look-sync.nvim). Report problems with the plugin in its repository.
