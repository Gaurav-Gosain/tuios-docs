tuios 0.12.2 lets you move the daemon to a new build without ending a single pane. Linking another machine is one command, `tuios hosts setup`. Agents get task boards with dispatch, and an agent can hand a task to a child agent and get the answer back by mail. Quick look reads much more, plugins get a full toolkit, and bash and zsh panes get prompt marks with no change to your files. [What's new](/docs/whats-new) has the short version, with a link to each page.

## Install

```bash
brew install tuios                     # Homebrew (macOS, Linux)
yay -S tuios-bin                       # AUR (tuios-web-bin for the web server)
nix run github:Gaurav-Gosain/tuios     # Nix
curl -fsSL https://raw.githubusercontent.com/Gaurav-Gosain/tuios/main/install.sh | bash
go install github.com/Gaurav-Gosain/tuios/cmd/tuios@v0.12.2
docker run -it --rm ghcr.io/gaurav-gosain/tuios:v0.12.2
```

A binary installed by the script or from an archive updates with `tuios update`. From this release, the install script and `tuios update` move a running daemon to the new build with a live upgrade when they can, so the programs in your panes keep running. When they cannot, run `tuios restart-server`. See [Upgrade in place](/docs/daemon-restart#upgrade-in-place).

## Highlights

- **Live upgrade.** `tuios daemon upgrade` moves a running daemon to a new binary without
  ending your panes, and the installers and `tuios update` use it when they can. A
  client follows the daemon across the upgrade. ([#1333](https://github.com/Gaurav-Gosain/tuios/pull/1333), [#1398](https://github.com/Gaurav-Gosain/tuios/pull/1398), [#1480](https://github.com/Gaurav-Gosain/tuios/pull/1480), [#1593](https://github.com/Gaurav-Gosain/tuios/pull/1593), by
  @abhijit-s)
- **Set up a machine in one command.** `tuios hosts setup` links another machine step
  by step, asks for what it needs, picks tailnet machines from a list, and names an ssh
  failure with its fix. tuios offers to add a machine when a pane logs in to it with ssh.
  ([#1601](https://github.com/Gaurav-Gosain/tuios/pull/1601), [#1608](https://github.com/Gaurav-Gosain/tuios/pull/1608), [#1612](https://github.com/Gaurav-Gosain/tuios/pull/1612), [#1616](https://github.com/Gaurav-Gosain/tuios/pull/1616), [#1597](https://github.com/Gaurav-Gosain/tuios/pull/1597), [#1609](https://github.com/Gaurav-Gosain/tuios/pull/1609))
- **Task board.** The agents view shows the task board as kanban columns, with a card
  lifecycle, Ready to merge, project boards and auto dispatch. ([#1548](https://github.com/Gaurav-Gosain/tuios/pull/1548), [#1748](https://github.com/Gaurav-Gosain/tuios/pull/1748), [#1726](https://github.com/Gaurav-Gosain/tuios/pull/1726),
  [#1746](https://github.com/Gaurav-Gosain/tuios/pull/1746), [#1733](https://github.com/Gaurav-Gosain/tuios/pull/1733))
- **Child agents.** An agent can delegate a task to a child agent and get the answer
  back by mail. Children are linked to their parent, show in its thread, and their
  approvals and questions route to the person. ([#1565](https://github.com/Gaurav-Gosain/tuios/pull/1565), [#1574](https://github.com/Gaurav-Gosain/tuios/pull/1574), [#1575](https://github.com/Gaurav-Gosain/tuios/pull/1575), [#1576](https://github.com/Gaurav-Gosain/tuios/pull/1576), [#1562](https://github.com/Gaurav-Gosain/tuios/pull/1562))
- **Quick look reads much more.** Long files in windows, search and go to line, PDF
  pages, film strips, more file kinds, Markdown with HTML, alerts, footnotes and
  Mermaid, and copy mode over the preview. ([#1447](https://github.com/Gaurav-Gosain/tuios/pull/1447), [#1451](https://github.com/Gaurav-Gosain/tuios/pull/1451), [#1452](https://github.com/Gaurav-Gosain/tuios/pull/1452), [#1455](https://github.com/Gaurav-Gosain/tuios/pull/1455), [#1458](https://github.com/Gaurav-Gosain/tuios/pull/1458), [#1462](https://github.com/Gaurav-Gosain/tuios/pull/1462),
  [#1684](https://github.com/Gaurav-Gosain/tuios/pull/1684))
- **Plugins grow up.** `tuios plugins new`, `check`, `dev`, `update` and `stats`, the
  first-party plugins install from the release, a `ui` grant with dock cells, themes and
  screen savers as plugins, and a written plugin API. ([#1456](https://github.com/Gaurav-Gosain/tuios/pull/1456), [#1457](https://github.com/Gaurav-Gosain/tuios/pull/1457), [#1466](https://github.com/Gaurav-Gosain/tuios/pull/1466), [#1473](https://github.com/Gaurav-Gosain/tuios/pull/1473), [#1484](https://github.com/Gaurav-Gosain/tuios/pull/1484),
  [#1460](https://github.com/Gaurav-Gosain/tuios/pull/1460), [#1499](https://github.com/Gaurav-Gosain/tuios/pull/1499), [#1500](https://github.com/Gaurav-Gosain/tuios/pull/1500))
- **Prompt marks in bash and zsh.** tuios turns on OSC 133 marks in the shells it starts,
  without editing your files, so the scrollback browser, `tuios run` and copy mode know
  where each command starts and ends. ([#1611](https://github.com/Gaurav-Gosain/tuios/pull/1611))
- **Drag and drop with the desktop.** Drags go to and from the desktop through kitty's
  drag and drop protocol. ([#1374](https://github.com/Gaurav-Gosain/tuios/pull/1374), [#1530](https://github.com/Gaurav-Gosain/tuios/pull/1530), by @dschmidt)

## Before you upgrade

- The rarer Mermaid diagram types moved to the `sketch` plugin. Eight common types
  still draw in tuios. For the rest, run `tuios plugins install sketch`. ([#1467](https://github.com/Gaurav-Gosain/tuios/pull/1467), [#1505](https://github.com/Gaurav-Gosain/tuios/pull/1505))
- bash and zsh panes now get OSC 133 prompt marks. Set `[shell] integration = "off"`
  to start shells as before. ([#1611](https://github.com/Gaurav-Gosain/tuios/pull/1611))
- The ghostty backend now uses libghostty-vt 1.0. Rebuild it with
  `scripts/install.sh ghostty`. ([#1775](https://github.com/Gaurav-Gosain/tuios/pull/1775))
- The binary size ceiling is now 50 MB. ([#1555](https://github.com/Gaurav-Gosain/tuios/pull/1555))

## Performance

- The binary is about 350 KB smaller: Errorf and JSON go out of line, and cold sorts and
  the lexer dictionary shrink. ([#1513](https://github.com/Gaurav-Gosain/tuios/pull/1513), [#1514](https://github.com/Gaurav-Gosain/tuios/pull/1514))
- The emulator stores only the content of plain cells on a scroll, and builds a screen's
  tail text in one buffer. ([#1495](https://github.com/Gaurav-Gosain/tuios/pull/1495), [#1519](https://github.com/Gaurav-Gosain/tuios/pull/1519), [#1625](https://github.com/Gaurav-Gosain/tuios/pull/1625) by @Gsirawan)
- Quick look keeps its panel until its content changes, searches and draws its matches
  in one walk, and keeps pictures smaller. ([#1437](https://github.com/Gaurav-Gosain/tuios/pull/1437), [#1584](https://github.com/Gaurav-Gosain/tuios/pull/1584), [#1618](https://github.com/Gaurav-Gosain/tuios/pull/1618), [#1620](https://github.com/Gaurav-Gosain/tuios/pull/1620), [#1628](https://github.com/Gaurav-Gosain/tuios/pull/1628), by
  @Gsirawan)
- The daemon sends no listing push for a spinner frame, checks a prompt gate only on its
  own pane's events, and hashes the state fingerprint more cheaply. ([#1594](https://github.com/Gaurav-Gosain/tuios/pull/1594); [#1617](https://github.com/Gaurav-Gosain/tuios/pull/1617), [#1435](https://github.com/Gaurav-Gosain/tuios/pull/1435),
  by @Gsirawan)
- Each TML surface renders with its own hooks and no lock. ([#1685](https://github.com/Gaurav-Gosain/tuios/pull/1685))
- Worktree rows read in one status walk each, concurrently. ([#1485](https://github.com/Gaurav-Gosain/tuios/pull/1485), by @davidreuss)
- sketch keeps its named themes static and its rare text drawers out of programs that do
  not use them. ([#1578](https://github.com/Gaurav-Gosain/tuios/pull/1578), [#1552](https://github.com/Gaurav-Gosain/tuios/pull/1552), by @Gsirawan)
- The GUI bridge parses each pane once. ([#1504](https://github.com/Gaurav-Gosain/tuios/pull/1504))
